Columns: Two-column layout

The columns block supports flexible multi-column layouts. Each row in the authoring table becomes a column. Use it for image + text combinations, side-by-side feature comparisons, or any content that benefits from a horizontal layout.

On mobile, columns stack vertically. On desktop (900px+), they display side by side with equal or proportional widths depending on content.

What is the accordion component used for?

The accordion is ideal for FAQ sections, expandable details, or any content where progressive disclosure helps reduce visual noise. Authors add items in the Universal Editor as child accordion-item components, each with a question and a rich text answer.

How does the open/close behavior work?

Clicking an accordion trigger toggles the panel open. When a new item is opened, all other open items close automatically — only one panel is open at a time. The component uses aria-expanded, aria-controls, and role="region" for full accessibility compliance.

Is the accordion keyboard navigable?

Yes. Each trigger is a native HTML button element, so it's fully keyboard accessible. Users can Tab to each trigger and use Enter or Space to toggle. The panel content is also reachable via Tab when the panel is open.

Can I have multiple accordions on one page?

Yes. Each accordion block is independently managed. Open state is scoped to the block — opening an item in one accordion does not affect items in another accordion on the same page.
